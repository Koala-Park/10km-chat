# 모아 — 사내 채팅

로그인 없이 같은 사내망의 사람들이 메시지와 파일을 공유하는 웹 채팅입니다. 채팅 기록은 서버의 `data/chat.db`(SQLite)에, 첨부 파일은 `data/uploads/`에 저장됩니다. 예전 버전의 `data/messages.json`이 있으면 처음 실행할 때 자동으로 `chat.db`로 옮기고, 원본은 `messages.json.migrated`로 남깁니다.

## 실행

Node.js 22.13 이상(내장 `node:sqlite` 사용)이 설치된 사내 서버에서:

```bash
npm start
```

서버 기본 포트는 `3000`이며, 기본적으로 물리 네트워크 인터페이스의 사설 IPv4 주소에 연결됩니다. 직원은 브라우저에서 서버에 표시된 주소로 접속하면 됩니다. 서버에 사설 IPv4 주소가 없으면 `127.0.0.1`에서만 실행됩니다. 인터페이스가 여러 개면 `HOST`로 사내망 IP를 지정하세요. 운영 환경에서는 방화벽이나 프록시로 **사내망에서만** 이 포트에 접근할 수 있도록 제한하세요. 이 앱에는 로그인과 사용자 인증이 없습니다.

포트와 저장 위치를 바꾸려면:

```bash
HOST=192.168.0.10 PORT=8080 DATA_DIR=/srv/moa-data npm start
```

파일은 화면에 드래그해서 놓거나 첨부 버튼으로 선택할 수 있고, 여러 개를 한 번에 올릴 수 있습니다. 스크린샷처럼 클립보드에 있는 이미지는 채팅 화면에서 붙여넣기(⌘V / Ctrl+V)로 첨부할 수 있습니다. 붙여넣기·드래그·첨부 버튼으로 고른 파일은 바로 보내지지 않고 입력창 위에 미리보기로 쌓이며, ×로 뺄 수 있고 메시지를 덧붙여 Enter로 함께 보냅니다. PNG·JPEG·GIF·WebP 이미지는 파일 내용으로 판별해 대화에 미리보기로 보여 주고, 누르면 원본을 새 탭에서 엽니다(SVG 등 그 밖의 형식은 다운로드만 됩니다). 이미지를 여러 장 한 번에 올리면 한 메시지에 바둑판 모양으로 묶어 보여 줍니다. 파일 크기 제한은 없으며, 올린 파일은 디스크에 바로 기록되어 `data/uploads/`에 남습니다. 큰 파일을 자주 올린다면 서버 디스크 여유 공간을 주기적으로 확인하거나 아래 자동 정리를 켜세요.

## 오래된 내용 자동 정리

기본값은 지우지 않음입니다. 보관 기간(일)을 환경 변수로 정하면 서버를 켤 때와 그 뒤 1시간마다 기간이 지난 메시지를 지우고, 파일 메시지는 `data/uploads/`의 파일도 함께 지웁니다. 접속해 있는 화면에서도 지워진 메시지가 바로 사라지고, 상단에 보관 기간이 표시됩니다.

| 변수 | 의미 |
| --- | --- |
| `RETENTION_DAYS` | 모든 메시지(글·파일)의 보관 기간 |
| `FILE_RETENTION_DAYS` | 파일 메시지만 더 짧게 보관할 때의 기간. `RETENTION_DAYS`와 함께 쓰면 둘 중 짧은 기간이 적용됨 |

```bash
# 대화는 90일, 파일은 30일 보관
RETENTION_DAYS=90 FILE_RETENTION_DAYS=30 npm start
```

로그인이 없는 앱이라 누구나 기록을 지울 수 없도록 화면이 아니라 서버 환경 변수로만 설정합니다. 지운 내용은 되돌릴 수 없으니 필요하면 먼저 `data/`를 백업하세요. 앞에 프록시(nginx 등)를 둔다면 프록시의 업로드 크기 제한(`client_max_body_size` 등)도 함께 풀어야 합니다. `data/`를 정기적으로 백업하면 대화와 파일을 함께 보존할 수 있습니다. 서버가 켜져 있는 동안에는 `chat.db-wal` 파일에도 최근 기록이 있으므로, 서버를 멈춘 뒤 복사하거나 `sqlite3 data/chat.db ".backup backup.db"`로 백업하세요. HTTPS가 필요한 사내 환경에서는 서버 앞에 TLS 프록시를 두세요.
